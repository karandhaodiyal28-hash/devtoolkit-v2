# Security Policy

## Supported versions

Only the latest published version is maintained.

| Version | Supported |
| ------- | --------- |
| latest  | yes       |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead:

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Describe the issue together with reproduction steps

You can expect an acknowledgement within 48 hours and a status update within
7 days.

## Scope

`devtoolkit` is a small, dependency-free helper library. Reports about
third-party services that the README links to are out of scope, since this
repository only links to them and does not run them.
